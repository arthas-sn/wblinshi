# 股票工具箱 Stock-Toolkit

统一网页：**高股息·超卖 选股器** + **日内做T助手**，单进程、单端口、手机可访问。

## 目录结构
```
stock-toolkit/
├── server.js            # 统一 Node 服务（单进程，托管两个功能 + 静态前端）
├── westock-tool.js      # 选股器依赖：腾讯自选股条件选股 CLI
├── t_engine/
│   └── t_engine.py      # 做T引擎：纯标准库 Python，输出 JSON（被 Node 子进程调用）
├── public/
│   ├── index.html       # 单页面双 Tab 前端
│   └── chart.umd.min.js # 本地 Chart.js（离线可用）
├── package.json
└── README.md
```

## 运行

### 本机开发
```bash
cd stock-toolkit
node server.js
# 浏览器打开 http://localhost:3000
```
- 选股器：依赖 `node`（直接用，无需安装 npm 包）。
- 做T引擎：依赖 Python3。本机若直连被 reset，需走代理：
  ```bash
  # Windows 本机（走 7890 代理）
  set T_PROXY=http://127.0.0.1:7890
  set PYTHON_BIN=C:/Users/yuwell/.workbuddy/binaries/python/versions/3.13.12/python.exe
  node server.js
  ```

### 服务器部署（推荐，你已有选股器服务器）
国内服务器一般可直连腾讯/东财，无需代理。把整个 `stock-toolkit` 目录传上去：

```bash
# 1. 确保已装 node 与 python3
node -v && python3 --version

# 2. 启动（默认 3000 端口，可改 PORT 环境变量）
PORT=80 node server.js
# 或后台常驻：
nohup node server.js > toolkit.log 2>&1 &

# 3. 手机访问
# 浏览器打开 http://<服务器IP或域名>:80
```

环境变量（可选）：
- `PORT`：监听端口（默认 3000）。
- `T_PROXY`：做T引擎代理地址。设了才走代理，否则直连（服务器直连最快）。
- `PYTHON_BIN`：Python 解释器路径。默认 Windows=`python`、其他=`python3`；找不到时在此指定绝对路径。

## 接口
- `GET /api/screen?yield=3.5&rsi=35&pct=25&drawdown=25` → 高股息·超卖选股结果 JSON
- `GET /api/steady` → 稳健增长选股结果 JSON（PE>0 + 连续5年分红 + 近5个报告期 归母净利>0/同比>0/经营现金流>0）
- `GET /api/t?code=600000` → 做T信号 JSON
- `GET /` → 统一前端页面

## 稳健增长选股器说明
- 判定口径：**近5个年报**（12-31期，非季报/中报），每个年报同时满足 归母净利润>0、净利润同比>0、每股经营现金流>0；避免中报/季报单季同比波动造成误判（如某公司22年年报-11%但23年中报+38%这类）。
- 三段式数据链路：westock 粗筛（PE_TTM>0 且 TTM 股息率>0，约 3 千只）→ 东财业绩报表**逐年精确拉取**近6年年报期（每年5千余条，本地判定近5年报三条件全过）→ 幸存者逐只到新浪核验连续派息≥5 年（8 路并发 + 12 小时缓存）。
- 缓存：财务批量 2 小时（年报变化极少）、粗筛池 10 分钟、分红核验 12 小时、整条结果 5 分钟。首次约 1~2 分钟，之后秒出。
- 同比用 SJLTZ（归母净利润同比增长率）；同一报告期有修订版时取 UPDATE_DATE 最新。

## 说明
- 选股器主筛选=腾讯自选股；连续派息=新浪；市现率=东方财富。
- 做T助手：分时均价线 + 量价背离 + 分时MACD(5,34,5) + KDJ(9,3,3) + 布林带(20,2)，≥2 条件共振出信号。
- 做T质量优化（2026-10-09 回放验证）：① 正T开盘冷静期 20 分钟（09:50 前不发买入，早盘惯性下杀是正T失败重灾区）；② 止损宽度 max(5分, 2×保本)（原 3 分止损 19% 被噪音打掉后又回升，放宽后严格达标率与体验双升）。均经今日 100 只 + 历史 6 只×5 日交叉验证；"创新低不接/企稳确认/贴均超时/战绩暂停"等买侧闸门实测均为负优化，未采纳。
- 达标率定义（回放口径）：信号后 30 分钟窗口内，先触及回归目标（=成本向上取整到分）且未先触发止损线，计为一次成功。
